# Audit materi Tools AI untuk peserta kelas 11

## Brief

Peserta sudah biasa coding dan familiar dengan AI. Materi berfokus pada AI-Assisted Development, dengan perbandingan Vibe Coding tetap dipertahankan. Developer bertanggung jawab atas kode yang digunakan. Istilah Tools AI dan micro task dipertahankan; bahasa slide netral dan profesional. Kasus formulir Nama diganti dashboard penjualan.

## Perubahan substansi

- 33 slide, 10 bab dengan menu ringkas: Pengantar, Risiko, Tools AI, Konteks, Panduan, Review, Micro Task, Simulasi, Evaluasi, Laporan.
- Risiko dibedakan menjadi sycophancy, halusinasi, dan klaim selesai tanpa bukti yang sesuai.
- Pendalaman mencakup context pack, task contract, acceptance criteria, scope konfigurasi, review hipotesis/rencana/diff, regression test, dan keputusan penerimaan.
- Kasus omzet memakai dataset simulasi yang sama pada slide dan demonstrasi. Dashboard dan CSV memakai fungsi agregasi bersama.
- Versi awal Rp3.800.000; perbaikan parsial Rp3.300.000; hasil sesuai aturan Rp3.000.000. Refund, timezone, dan integrasi produksi berada di luar scope yang dinyatakan.

## Temuan review dan perbaikannya

**MEDIUM, R-02 dan R-38:** Contoh sycophancy awal hanya menampilkan dugaan cache pengguna dengan label usulan AI. Label diperbaiki menjadi DUGAAN PENGGUNA dan respons AI yang terlalu menyetujui ditampilkan terpisah dalam simulasi. Pengujian baru gagal sebelum perbaikan lalu lulus setelahnya.

## Delivery Gate

- **PASS, fungsi dan bukti:** `verify-tefa-sales.cjs` pertama gagal saat final masih menghasilkan Rp3.300.000. Sesudah perbaikan ke aturan completed, hasil ketiga tahap benar. Kasus completed, cancelled, pending, periode lain, data kosong, status tidak dikenal, serta total ekspor lulus.
- **PASS, CSV nyata:** Unduhan CSV dibuka melalui stream browser, bukan hanya membaca pesan sukses. Isi memuat tiga transaksi completed dengan total Rp3.000.000 dan header yang sesuai.
- **PASS, kontrol demonstrasi:** Tiga tahap bisa dipilih. Filter periode mengubah data dan total; periode kosong menampilkan empty state; tombol ekspor menghasilkan unduhan. Tautan dari slide benar-benar membuka dashboard pada tahap yang sesuai.
- **PASS, layout:** Seluruh 33 slide dengan pembahasan terbuka diperiksa pada 1920×1080, 1440×900, 1366×768, 1024×768, 768×1024, 390×844, dan 320×568. Tidak ada clipping horizontal atau scroll pada laptop/proyektor. Ponsel dapat menggulir isi.
- **PASS, navigasi dan ketahanan:** Semua tujuan bab, keyboard, hover, konteks pilihan, percakapan manual, persistence, notes, mode fokus, salin instruksi, fullscreen, reduced-motion, serta fallback penyimpanan/WebGL diperiksa. Tidak ada error JavaScript.
- **PASS, offline:** Suite slide mencatat nol request eksternal dan nol request gagal. Semua angka berasal dari script data/engine yang disertakan. README menegaskan folder `examples/sales-report/` wajib ikut diunggah ke hosting statis.
- **PASS, copywriting:** Bahasa profesional yang netral, tidak memakai narasi saya/kita/kami atau istilah contoh lokal. Tidak ada em/en dash pada data materi. Istilah Tools AI dan micro task tetap digunakan. Sumber rujukan tidak disalin sebagai klaim mutlak tentang AI.
- **PASS, kejujuran:** Nilai transaksi ditandai dataset simulasi dan tidak disebut sebagai data penjualan nyata. Percakapan adalah rekonstruksi simulasi. Klaim pengujian dibatasi ke demonstrasi statis melalui Microsoft Edge.
- **PASS, kontras bidang baru:** Status completed 6,52:1; cancelled 6,80:1; pending 6,48:1; caption 7,33:1 terhadap bidang terang, dihitung dengan rumus luminansi WCAG. Tidak ada klaim audit WCAG menyeluruh atau uji proyektor dari jarak nyata.
- **PASS, purpose dan liveliness:** Tabel langsung menjaga ketajaman teks dan keterlacakan angka. Perbandingan aturan menghubungkan implementasi dengan hasil bisnis. Layout bervariasi menurut isi; typography judul dan menu mengikuti arah P3R. ENERGY 3 / RHYTHM 3 / MOTION 3 untuk navigasi tetap berlaku; isi diam saat dibaca.
- **PASS, craftsmanship:** Screenshot kasus, perbandingan aturan, pengujian, pembuka, perbandingan pendekatan, dan sycophancy diperiksa. Sintaks JavaScript dan `git diff --check` lulus. Tidak ada temuan review yang ditunda.

Audit ini memeriksa lingkup materi dan demonstrasi, bukan mengklaim kesamaan piksel dengan game atau skor deteksi penulisan AI.
