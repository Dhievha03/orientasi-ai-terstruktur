# Bukti simulasi formulir

Gambar dalam folder ini diambil dari `examples/registration/` melalui browser. Versi sebelum, perbaikan pertama, dan perbaikan akhir dipisahkan agar urutan kasus dapat diperiksa kembali. Gambar bukan hasil generasi atau jawaban layanan AI langsung.

Area tangkapan hanya memuat isian Nama dan pesan hasil. Penjelasan kondisi dan tahap perbaikan disediakan sebagai caption slide, tanpa istilah implementasi tambahan di dalam gambar. Dimensi gambar adalah 504 × 210 px.
