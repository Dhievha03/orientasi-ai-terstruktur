# Delapan Ending Ujian Online

## Acuan pemateri

Naskah terakhir dalam percakapan menggantikan skenario lama. Konflik adalah bug aturan, dugaan User, sycophancy, halusinasi penyimpanan, dan klaim selesai tanpa bukti. Delapan ending mengikuti akibat atau penyelesaian khusus, bukan satu tombol penggunaan.

## Implementasi

- [x] Adegan ditulis khusus dengan dua atau tiga pilihan chat, aktivitas, atau reaksi.
- [x] Tidak ada alur pemulihan akun, installer, atau penggantian versi.
- [x] Narator menyebut pelaku aktivitas.
- [x] E1 aturan terbukti, E2 penyimpanan terbukti, E3 hasil ditolak, E4 pesan disembunyikan, E5 data hilang, E6 halaman hilang, E7 nuklir, E8 overheat.
- [x] Permintaan ke-9 berhenti sebelum efek dijalankan. Aktivitas dan reaksi penutup tidak dihitung.
- [x] Reaksi nuklir adalah TUNGGU, MAKSUD SEMUA ITU YANG ADA DI APPS! atau ...
- [x] Bagian awal konklusi menunjukkan letak kesalahan dan bukti dari perjalanan aktual.
- [x] Saat pilihan tampil, textbox tersembunyi dan User netral. Ekspresi berubah hanya saat dialog terpilih tampil.
- [x] Lanjut dari narasi terakhir langsung membuka konklusi. Snapshot end tetap divalidasi host sebelum perpindahan. Tidak ada autoplay.
- [x] Asap memakai volume berlapis dan tepi terdeformasi. Petir singkat hanya di sekitar kepala. Reduced-motion menampilkan efek statis.
